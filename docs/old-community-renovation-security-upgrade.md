# 住建部要求老旧小区改造必须同步安防升级,利旧方案为什么是最优解?

2026年,全国城镇老旧小区改造进入攻坚阶段。

住建部在今年的改造指导文件中明确要求:**老旧小区改造必须同步推进安防设施智能化升级**。这意味着,过去那种"刷墙铺路装路灯"的面子工程模式已经不够了——安防系统被列入了改造的必选项。

这对物业公司和弱电集成商来说,既是业务机会,也是一个具体的难题。

## 老旧小区的安防现实

根据行业数据,全国70%的小区安防系统仍停留在"被动录像"阶段。老旧小区的情况更突出——摄像头清晰度低、布线老化、存储设备陈旧,很多小区的监控系统实际处于半瘫痪状态。

而法律风险正在逼近。2026年6月,深圳某物业公司因监控管理不到位、未能及时响应业主反馈的安全隐患,在一起高空抛物引发的火灾事故中被判承担相应责任。法院的认定逻辑很清晰:物业有义务维护监控系统的有效运行,系统失效等同于管理失职。

对物业公司来说,安防已经不是一个"要不要升级"的问题,而是一个"能不能承担不升级的后果"的问题。

## 全量替换的账,算不过来

传统思路是:既然要改造,就把老摄像头全换掉,一步到位上AI智能摄像头。

一个典型的老旧小区,一般有100到150路摄像头。如果全部更换为AI智能摄像头,单路成本在2000到5000元之间。拿112路摄像头算一笔账:

| 项目 | 单价 | 数量 | 小计 |
|------|------|------|------|
| AI智能摄像头 | 3000元/路 | 112路 | 33.6万 |
| 布线施工 | 约500元/路 | 112路 | 5.6万 |
| NVR/存储设备升级 | — | — | 约8万 |
| 平台授权/调试 | — | — | 约5万 |
| **合计** | | | **约52万** |

对很多老旧小区来说,整个改造预算可能也就两三百万,光是安防一项就占去五分之一。实际操作中,要么安防升级被砍掉,要么降标敷衍了事——装几个新摄像头,但AI分析能力完全没到位,最终又回到"被动录像"的老路。

## 利旧改造:一个被低估的路径

住建部强调安防智能化升级,重点在"智能化"三个字,不在于换了多少摄像头。

目前的技术路径中,边缘AI利旧改造是一个在成本和效果之间比较均衡的方案。它的核心逻辑是:在机房加装一台边缘AI服务器,通过RTSP协议接入原有摄像头的视频流,在本地完成全部AI分析,只把告警结果推送给管理人员。

以112路摄像头的老旧小区为例:

- **硬件投入**:一台边缘AI服务器,约5万左右
- **施工**:机房接入交换机,不需要砸墙布线,1天内完成
- **摄像头**:全部利旧,一个不用换
- **部署周期**:3-7天上线的完整系统

与传统全量替换方案对比:

| | 全量替换 | 边缘AI利旧 |
|------|------|------|
| 硬件投入 | 约40-52万 | 约5万 |
| 施工周期 | 2-4周 | 1-7天 |
| 是否需要换摄像头 | 全部更换 | 一个不换 |
| 是否需要布线 | 需要 | 不需要 |
| AI分析能力 | 强 | 强(同样支持100+场景) |
| 告警响应速度 | 秒级 | 秒级 |
| 后续扩展 | 换更多摄像头 | 远程OTA升级模型 |

两种方案在AI分析能力上没有本质差别。区别在于实现方式:一个是推倒重建,一个是在存量基础上做加法。

## 老旧小区AI安防需要覆盖哪些场景?

住建部的改造指导文件里,虽然没列出具体的技术参数,但对"智能化"有明确的功能方向要求。结合行业实践,老旧小区改造中的AI安防至少需要覆盖以下几个场景:

1. **消防通道占道检测**:老旧小区消防通道被车辆、杂物占用是普遍问题,AI自动识别并即时告警,比定时人工巡查有效得多。

2. **电动车违规进楼识别**:电动车进电梯、进楼道是引发火灾的高危行为,AI视觉分析可以在电动车进入电梯轿厢时触发梯控联动,阻止电梯关门。

3. **高空抛物溯源**:老旧小区缺乏对空监控,高空抛物取证困难。AI分析对建筑物的立面监控视频,可以追溯抛物的时间、楼层、窗口。

4. **周界入侵告警**:老旧小区围墙低、出入口多,周界防范薄弱。AI自动识别翻墙、越界行为并即时推送到保安手机。

5. **异常聚集识别**:人员异常聚集、打架斗殴等事件,AI可以在现场态势升级之前触发预警。

这些场景不需要"最好的摄像头"。原摄像头只要满足1080P以上的分辨率,边缘AI服务器就能完成准确率在90%以上的分析。

## 一个需要先确认的问题:摄像头画质

利旧改造有一个前提条件:原有摄像头的画质不能太差。

如果摄像头是2015年以前的模拟标清设备(分辨率低于720P),即使是边缘AI也难以准确识别。这种情况需要先把摄像头升级到1080P数字摄像头(200-300元/路),再接入AI服务器。即使如此,整体成本也比全量替换低一个数量级。

但如果摄像头是2018年以后建设的,大概率已经满足基本要求,只需要确认画质达标即可。

判断标准很简单:保安在监控室能不能看清人脸?看不清的话,AI也看不清。

## 资金从哪来?老旧小区改造有三条路

老旧小区改造的资金来源,根据各地政策差异,通常有以下几种渠道:

1. **政府补贴+专项债**:中央和省级财政对老旧小区改造有专项资金支持,安防智能化升级作为改造的子项目可以申请。部分地区补贴比例可达50%-70%。

2. **维修基金**:对于有维修基金的小区,安防升级属于公用设施设备改造,可以合法使用维修基金。但需要业主投票通过,流程周期在2-3个月。

3. **物业自筹**:部分物业公司会自己出资做安防升级,通过物业费调价或增值服务逐步回收。前面的账算过——如果全量替换要52万,物业自筹压力很大。但如果走利旧改造只需要5万,回本压力就小得多。

这其实才是住建部政策在落地层面的真实矛盾:要求是刚性的,但很多小区的资金是有限的。如果只有全量替换一条路,大量小区会卡在资金环节,政策效果大打折扣。利旧改造在这个意义上,不仅是省钱的问题——它是让政策真正落地的技术路径。

## 不只是老旧小区,也不只是住建部的要求

实际上,把"安防智能化"写进硬性要求的,不只是老旧小区改造这一项政策。北京已经在2026年试点*住宅物业企业技防能力要求*,将AI视频分析列入物业企业的基础能力评价。这意味着,以后物业公司能不能接项目、能不能续约,安防能力会成为一个硬指标。

这在逻辑上是通的——如果物业收了管理费但监控系统形同虚设,出了事谁来负责?深圳的判决已经给出了答案。
